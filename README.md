# Jaytail releases

Official release binaries of [Jaytail](https://jaytail.dev), a fast pager for JSON Lines logs.

This repository holds releases only. Jaytail is proprietary software; its source code is not
published here.

- Install: https://jaytail.dev (the installers verify each archive's SHA-256)
- Every release: archives for Linux, macOS and Windows (standard and minimal builds) and
  `SHA256SUMS`
- License: [EULA](https://jaytail.dev/legal/eula/); third-party notices are in every archive
  (`THIRD-PARTY-LICENSES.md`) and at https://jaytail.dev/legal/notices/
- Security reports: https://jaytail.dev/security/
